# Проектная работа. RAG-бот для QuantumForge Software

Ответы на задания спринта. Подробные решения и обоснования - в директориях `Task1` ... `Task7`.

## Задание 1. Исследование моделей и инфраструктуры

Полный отчёт: [Task1/README.md](Task1/README.md).

Кратко:

- **LLM**: гибридная схема - локальная модель (Qwen2.5-14B через vLLM) для запросов по конфиденциальным/клиентским данным, облачная (GPT-4o-mini) для открытой внутренней документации.
- **Эмбеддинги**: локальная модель bge-m3 для всего корпуса без исключений - индексация затрагивает весь контент, включая закрытый, поэтому конфиденциальность здесь критичнее, чем для генерации ответа.
- **Векторная БД**: ChromaDB как основная БД для продакшна - встроенная персистентность, метаданные и upsert/delete удобны для растущей и часто обновляемой базы знаний (~400 страниц/месяц, ежедневное автообновление). FAISS - для локального прототипирования на этапе разработки.
- **Сервер**: 8-16 vCPU, 32-64 ГБ RAM, 1x GPU уровня NVIDIA A10G/L4 (24 ГБ VRAM), SSD от 200 ГБ, размещение в приватном VPC-сегменте существующего EKS.
- **Рекомендация**: гибридный вариант (локальные эмбеддинги + ChromaDB + маршрутизация LLM между локальной и облачной моделью в зависимости от чувствительности данных).
