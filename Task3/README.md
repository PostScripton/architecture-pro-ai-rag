# Задание 3. Создание векторного индекса базы знаний

## Модель эмбеддингов

- Модель: `BAAI/bge-m3` (та же, что выбрана и обоснована в Задании 1).
- Репозиторий: https://huggingface.co/BAAI/bge-m3
- Размерность эмбеддинга: 1024.
- Локальная модель, инференс на CPU через `sentence-transformers` / `langchain-huggingface`.

## База знаний

Использована база знаний из [Задания 2](../Task2/README.md) - 45 файлов `.md` в `Task2/knowledge_base/` (вымышленная вселенная на основе Star Wars, персонажи, планеты, техника, фракции, события).

## Чанкование

- Инструмент: `RecursiveCharacterTextSplitter` из LangChain.
- Размер чанка: 1000 символов, перекрытие: 150 символов.
- Разделители подобраны по смысловым границам текста: сначала подзаголовки (`## `), затем абзацы, строки, предложения и слова.
- Для каждого чанка сохранены метаданные: `source` (путь к исходному файлу), `title` (заголовок статьи), `chunk_id` (порядковый номер чанка в индексе) - это нужно для цитирования источника в ответах бота.

## Индекс

- Векторная БД: FAISS (embedded-вариант, выбранный в Задании 1 для прототипа спринта).
- Код построения индекса: [build_index.py](build_index.py).
- Результат сохранён в [faiss_index/](faiss_index/) (`index.faiss` + `index.pkl`).

## Статистика индексации

- Документов: 45.
- Чанков: 393.
- Время генерации эмбеддингов и построения индекса: около 9 секунд (CPU, без GPU).
- Полная статистика - [index_stats.json](index_stats.json).

## Проверка качества поиска

Код проверки - [query_index.py](query_index.py), результаты сохранены в [query_examples.txt](query_examples.txt).

Проверено 3 запроса, для каждого выведены топ-3 найденных чанка с оценкой релевантности (косинусное расстояние, чем меньше - тем ближе) и метаданными источника:

1. "Who trained Toren Kaelis and why was the High Council reluctant to accept him?" - найдены чанки из статей про Thuun (наставника) и Murkveil (место обучения), корректно описывающие обучение Toren Kaelis / Peren Kaelis.
2. "What happened during the Night of Sorrow?" - найден чанк из статьи про Thuun с описанием этого события, а также релевантные по теме войн чанки про Machine Wars и Nyxari.
3. "Describe the Void Core battle station and its purpose." - топ-3 результата все из статьи про Void Core, с описанием станции и её боевых модификаций DS-1/DS-2.

Во всех примерах индекс возвращает содержательные и релевантные фрагменты, при этом термины вселенной остаются в вымышленном виде (Thuun, Kaelis, Void Core, Nyxari) - это подтверждает, что поиск опирается именно на подготовленную базу знаний, а не на память модели эмбеддингов.
