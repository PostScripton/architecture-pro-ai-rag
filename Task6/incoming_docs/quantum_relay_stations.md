# Ретрансляционные станции Квантовой Сети

Ретрансляционные станции - узловые сооружения, поддерживающие стабильную
связь между отдалёнными секторами через Квантовую Сеть. Каждая станция
оснащена резонатором синхронизации, который компенсирует временные сдвиги
при передаче сигнала на межзвёздные расстояния.

## Расположение

Станции размещены на нейтральных астероидных полях, вне юрисдикции
отдельных фракций, что делает их удобной площадкой для переговоров между
враждующими сторонами.

## Обслуживание

Ремонтные бригады станций набираются из инженеров-нейтралов, не связанных
с Альянсом Свободных Миров или Ковенантом Пустоты. Это правило введено
после инцидента на станции "Рубеж-7", когда диверсия одной из фракций
почти вывела сеть связи из строя на неделю.
