# Задание 4. RAG-бот с техниками промптинга

## Пайплайн

Модуль [rag_bot.py](rag_bot.py) реализует полный цикл RAG:

1. Запрос пользователя превращается в эмбеддинг той же моделью, что и при построении индекса в [Задании 3](../Task3/README.md) - `BAAI/bge-m3`.
2. По эмбеддингу в индексе FAISS ([Task3/faiss_index](../Task3/faiss_index)) ищутся 4 ближайших чанка (`similarity_search_with_score`).
3. Если лучший найденный чанк недостаточно релевантен (score выше порога), бот сразу отвечает "I don't know" без обращения к LLM - это отдельная защита от галлюцинаций поверх системного промпта.
4. Иначе из найденных чанков собирается контекст с указанием источника (`title`, `source`) и вместе с системным промптом, Few-shot примерами и вопросом пользователя отправляется в LLM.
5. LLM возвращает рассуждение (Chain-of-Thought) и итоговый ответ, бот выводит его пользователю вместе со списком источников.

Промпты и few-shot примеры составлены на английском - на том же языке, что и вся база знаний ([Task2/knowledge_base](../Task2/knowledge_base)). Смешение языков в промпте заметно ухудшает связность ответов лёгкой локальной модели, использованной как офлайн-бэкенд.

## LLM-бэкенд

Бэкенд выбирается автоматически в `LLMBackend`:

- если задана переменная окружения `OPENAI_API_KEY` - используется облачная модель `gpt-4o-mini` через `langchain-openai` (модель, рекомендованная для открытой внутренней документации в [Задании 1](../Task1/README.md));
- иначе - локальная модель `Qwen/Qwen2.5-0.5B-Instruct` через `transformers`, облегчённый вариант той же линейки моделей Qwen2.5, что рекомендована в Задании 1 (там - 14B на vLLM с GPU), но урезанный до размера, который реально выполняется на CPU окружения разработки. Так пайплайн можно полностью проверить локально и без API-ключей.

Для генерации у локальной модели используется жадное декодирование (`do_sample=False`) с `repetition_penalty=1.15` для стабильности и greedy-семплированием без сюрпризов, а начало ответа подсказывается префиксом `Reasoning:\n1.` (forced-prefix decoding) - без этого приёма модель на 0.5B параметров не всегда самостоятельно выдерживает структуру Chain-of-Thought.

## Few-shot prompting

В системный промпт добавлены два примера вопрос-ответ, взятые непосредственно из базы знаний (см. также [Task3/query_examples.txt](../Task3/query_examples.txt)):

- вопрос про Void Core (боевую станцию) с ответом на основе реального фрагмента статьи `death_star.md`;
- вопрос про наставника Peren Kaelis с ответом на основе реального фрагмента статьи `yoda.md`.

Оба примера показывают модели ожидаемый формат: раздел `Reasoning:` с пронумерованными шагами, затем `Answer:` с итоговым выводом.

## Chain-of-Thought

Системный промпт явно требует от модели сначала перечислить шаги рассуждения в разделе `Reasoning:`, а затем дать краткий итог после `Answer:`. Это уменьшает число прямых "угадываний" и делает видимым, на какие именно фрагменты контекста опирается ответ.

## Защита от галлюцинаций ("Я не знаю")

Помимо инструкции в системном промпте, добавлена отдельная проверка релевантности до вызова LLM: если оценка (косинусное расстояние FAISS, чем меньше - тем ближе) лучшего найденного чанка превышает порог `UNKNOWN_SCORE_THRESHOLD = 1.1`, бот возвращает "I don't know" не вызывая LLM.

Порог подобран эмпирически прогоном 6 вопросов по базе знаний и 5 вопросов не по теме базы:

- релевантные вопросы: лучший score в диапазоне 0.606-1.043;
- нерелевантные вопросы (пароль в Zendesk, столица Франции, Kubernetes ingress, рецепт печенья, курс акций Apple): лучший score в диапазоне 1.128-1.324.

Между двумя группами есть явный разрыв, поэтому порог 1.1 надёжно разделяет релевантные и нерелевантные запросы.

## Интерфейс

Выбран консольный REPL - интерфейс вторичен по отношению к самой цепочке RAG:

- `python3 rag_bot.py` - интерактивный режим, вопрос за вопросом;
- `python3 rag_bot.py -q "вопрос"` - разовый запрос из командной строки.

## Проверка

Пайплайн запущен и проверен целиком: загрузка индекса, эмбеддинг запроса, поиск, сборка промпта (few-shot + CoT), генерация ответа локальной моделью, вывод источников. Скрипт [run_examples.py](run_examples.py) прогоняет 5 вопросов по базе знаний и 2 вопроса не по теме базы и сохраняет полные диалоги в [examples_dialogs.md](examples_dialogs.md).

Результаты проверки:

- 5 успешных ответов по темам базы знаний (Void Core, обучение Peren Kaelis, разрушение Threnos, Ночь Скорби, добыча тибанны на Zephyra) - во всех случаях ответ грамотно опирается на найденный контекст, а раздел `Reasoning:` показывает, из какого источника взят факт.
- 2 случая с вопросами не по теме базы (сброс пароля в Zendesk, столица Франции) - в обоих бот честно отвечает "I don't know", не вызывая LLM, благодаря порогу релевантности.

Полные диалоги - в [examples_dialogs.md](examples_dialogs.md).
